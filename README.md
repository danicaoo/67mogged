# ТвойУнивер — проект для VS Code

## Запуск
1. Распакуйте архив.
2. Откройте папку `tvoyuniver-vscode` в Visual Studio Code.
3. Откройте `index.html` в браузере или используйте расширение **Live Server**.

## Структура
- `index.html` — главная
- `universities.html` — каталог вузов
- `specialties.html` — специальности
- `services.html` — сервисы абитуриента
- `admission.html` — этапы поступления
- `ege.html` — форма результатов ЕГЭ
- `styles.css` — общие стили всех страниц
- `script.js` — меню, анимации, поиск-демо и интерактивность формы
- `assets/logo.png` — предоставленный логотип

## Важно
Это фронтенд-прототип. Поиск, избранное, сохранение результатов и каталог пока работают в демонстрационном режиме; для реального хранения данных и актуальной базы вузов потребуется backend/API.
